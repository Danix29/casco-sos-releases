# Casco SOS - publicaciones de la app

Aqui solo se publica el APK de la app de Android de Casco SOS (proyecto PECL2, Computacion Ubicua, UAH) y su ficha `version.json`.
La app lo usa como respaldo para actualizarse cuando el servidor del proyecto no esta accesible.

No hay codigo fuente ni credenciales en este repositorio. Cada actualizacion se instala solo si esta firmada con la misma clave
que la app ya instalada y su SHA-256 coincide con el de `version.json`.
